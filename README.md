Student Performance Prediction

📌 Project Overview

This project uses Machine Learning to predict a student’s final score based on three factors:

* Study Hours
* Attendance Percentage
* Sleep Hours

The project was developed using Python and a Linear Regression model.

🛠️ Technologies Used

* Python
* Pandas
* Scikit-learn
* Linear Regression
* Git & GitHub

📊 Dataset

The dataset contains student information including:

* Study hours
* Attendance percentage
* Sleep hours
* Final score

🤖 Machine Learning Model

A Linear Regression model was trained using the student dataset.

The data was divided into training and testing sets, and the model was evaluated using the R² score.

The model achieved an R² score of approximately 0.99 on the test data.

🎯 Prediction

The model can accept new student information and predict their expected final score.

Example:

* Study Hours: 8
* Attendance: 97%
* Sleep Hours: 7

Predicted Final Score: 96.26

🚀 Purpose

This project was created as a Machine Learning portfolio project to practice data handling, model training, evaluation, and prediction.
